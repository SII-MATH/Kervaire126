# Synthetic 比较链整改记录

## 最高优先级规则

任何 `axiom` 或占位定理都必须表达有明确数学含义、并且在项目语义下确实为真的命题。
禁止使用无参数的 `axiom ... : Prop`、任意命题占位，或用空接口伪装完成度。

## 当前整改状态

上一轮错误地把未形式化的 δ-ESS、边界比较、crossing 和 Leibniz 结论写成了裸
`Prop` 公理。这些声明既没有对象、索引、映射，也不能被后续证明使用，已不再恢复。

当前只保留带完整类型的 `SyntheticAdamsESSShiftSystem` 外部输入，并新增
`DeltaESSBoundaryImages`，显式记录统一 ambient、δ-ESS 像和经典边界像。
像相等只定义为待证明命题 `DeltaESSBoundaryImages.Equal`，没有添加公理。

## 后续计划

1. 为 δ-ESS 像和经典边界像建立实际的 canonical 定义；
2. 构造它们之间的比较态射并证明子对象相等；
3. 在此基础上证明无穷/有限 δ 公式；
4. 再证明 crossing 等价并接入广义 Leibniz。
