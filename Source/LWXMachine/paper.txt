                                                   Abstract. In this document, we describe the process of obtaining numerous
                                                   Adams differentials and extensions using computational methods, as well as
                                                   how to interpret the dataset uploaded to Zenodo [6]. Detailed proofs of the
                                                   machine-generated results are also provided. The dataset includes information
                                                   on 49 CW spectra, 180 maps, and 61 cofiber sequences. Leveraging these
                                                   results, and with the addition of some ad hoc arguments derived through
                                                   human insight, we successfully resolved the Last Kervaire Invariant Problem
                                                   in dimension 126 [7].




                                                                              1. Introduction
                                              In this project, we first compute the Adams E2 -pages and maps for many CW
                                           spectra using the computer program ./Adams, developed by the first author [4].
                                           All relevant spectra and maps have been uploaded to the Zenodo repository [6]
                                           and are described in detail in Section 2. Additionally, another program, ./ss, also
                                           developed by the first author [4], computes Adams differentials and extensions. The
                                           resulting data are included in the Zenodo repository and described in Section 3.
                                              The program ./ss also generates proofs for all computed results, which are or-
                                           ganized into a comprehensive resource we refer to as the Table of Proofs. This pro-
                                           gram partially employs the Generalized Leibniz Rule and the Generalized Mahowald
                                           Trick—two theorems established in the paper [7] addressing the Last Kervaire In-
                                           variant Problem. These theorems enable the program to derive new differentials
                                           and extensions from previously computed ones. Detailed instructions on how to
                                           interpret and navigate the Table of Proofs are provided in Section 4.
                                              In Section 5, we present several charts and tables of machine-generated Adams
                                           differentials that are particularly relevant to the solution of the Last Kervaire In-
                                           variant Problem.

   Next we explain our naming scheme for the above CW spectra. We chose to
use plain text names for these objects because we want to use consistent names for
computer codes, command-line arguments for ./Adams and ./ss, the website links
of plots and the plain text machine proofs. Table 5 is a list of keywords we use in
the name and the corresponding elements in π∗ (S 0 ) the stable homotopy groups of

Remark 2.5. All the CW spectra we considered are connective spectra. The
current programs only work well with connective spectra.
Remark 2.6. If there are two or more CW spectra with different homotopy types
that satisfy the same naming condition, then the name represents all choices and
we do not assume which one we pick. The current important input of the program
is the existence of these cofiber sequences and the ones derived from these using
the properties of triangulated categories. We will make assumptions on homotopy
classes in the future when a new feature of the program is complete and it will enable
the ./ss program to rigorously determine if there exists at least one homotopy class
that satisfies multiple constraints.
  All the CW spectra we consider are known to exist in the literature. One major
example is the existence of tmf and its 15-skeleton

and we can get many subquotients of CW_sigma_nu_eta_2 and duals of these such
as CW_2_eta_nu. The existence of C2h4, C2h5, C2h6 is due to the strong Kervaire
invariant problem for σ 2 , θ4 , θ5 (See [1] [9]).

Notation 2.8. Let X,Y,Z be names of CW spectra. The following examples demon-
strate our naming for the maps between CW spectra.
       • If X has strictly fewer cells than Y and there exists a unique k and a unique
         inclusion (up to homotopy) such that X is a subcomplex of Σk Y, then X__Y
         denotes this subcomplex map X,→ Σk Y.
       • If X has strictly more cells than Y and there exists a unique k and a unique
         quotient such that Σk Y is a quotient complex of X, then X__Y denotes this
         quotient map X→ Σk Y.
       • If we have a cofiber sequence
                               X → Σm Y → Σn Z → ΣX
         whose first map is a subcomplex inclusion denoted by X__Y and whose
         second map is a quotient map denoted by Y__Z, then the third boundary
         map is denoted by Z__Q_Y.
       • For key words a,b,c,d,e, the map CW_d_e__CW_a_b_by_c is equivalent to
                             CW_d_e__Q_CW_a_b_c_d_e.
         Similarly, if we have a map with name X__Y_by_c it means that X has a
         unique bottom cell and Y has a unique top cell and the map attaches the
         bottom cell of X to the top cell of Y by c. In other words, these two cells
         form a subquotient of the cofiber of the map which is equivalent to Cc.
       • For numbers n,l,p,q where p < q = n − 1 < n < l, the map RPn_l__RPp_q
         is equivalent to RPn_l__Q_RPp_l. In other words, the following three maps
         form a cofiber sequence.

former differentials labeled with different reasons.
      • Rows with reason=‘d2’. This means that the d2 differential is calculated

     • Rows with reason=‘N’. This means that we get a differential from a pre-
       vious one by naturality.
     • Rows with reason=‘G’. This means that we get a trivial differential for
       degree reason.
     • Rows with reason=‘XX’. This corresponds to the case that if we have
       dr−1 (x) = 0 then we automatically get dr (x2 ) = 0.
     • Rows with reason=‘XY’. This corresponds to the case that if we have
       dr−1 (x) = 0 then no matter what dr (x) is (when there are two candi-
       dates or more), we always get the same value for dr (xy) by Leibniz rule or
       dr (f (x)) by naturality.
     • Rows with reason=‘ToCs’. This means that in the extension spectral
       sequence, we have tried all possible values of an extension (linear combina-
       tions of elements in the E2 -page) and the outcome is that certain element in
       the Adams spectral sequence should survive to the E∞ -page and it becomes
       a summand of the value of the extension.
     • Rows with reason=‘OutCsI’. This means that in the extensions spectral
       sequence, two permanent cycles should be the same on the E∞ -page. Hence
       the difference dx should be hit by an Adams differential. In those rows the
       columns stem,s,t refer to the degree of dx in stead of x.
     • Rows with reason=‘CsCm’. These are extensions obtained from some sim-
       ple homotopy relations. For example, if x ∈ E∞ (S 0 ) is the target of an
       η-extension, then it should detect a ν-torsion (dνn (η) = 0 for all n) because
       we know that η · ν = 0 ∈ π∗ (S 0 ). The reader can find more property of
       extensions in [7].
     • Rows with reason=‘Syn’. This means that the differential is obtained by
       the Generalized Leibniz Rule from the former row. The map used in the
       Generalized Leibniz Rule and the conditions that the machine checked is
       written in the info column.
     • Rows with reason=‘SynCs’. This means that the row is an extension and
       is obtained by the Generalized Mahowald Trick. The cofiber sequence used
       in the Generalized Mahowald Trick and the conditions that the machine
       checked is written in the info column.
     • Rows with reason=‘SynIn’. This means that by the Generalized Ma-
       howald Trick we determine that an element in the Adams spectral sequence
       should be a permanent cycle and become a summand of an extension.
     • Rows with reason=‘TI’, ‘DI’, ‘GI’. These are essentially the same as
       rows with reason=‘T’, ‘D’, ‘G’ except that the columns stem,s,t refer
       to the degree of dx in stead of x. For consecutive rows with reason=‘TI’
       the machine are enumerating possible sources of some differential (when we
       know dx is hit by some dr differential beforehand) instead of the possible
       targets and the conclusion row is one with reason=‘DI’.


Remark 4.4. If the reader wants to search for a proof of certain differential, then
usually you need to search for the bidegree of the source of the differential with
reason=‘D’ or reason=‘T’. Occasionally the machine knows the target should
be hit by a certain differential first and deduces the differential by enumerating the
possible sources. In this case you also need to search for the bidegree of the target
of the differential with reason=‘DI’ or reason=‘TI’.
